# Surtidora de Aves 22 DR — Proyecto Web

Estructura modular del sitio web oficial de **Surtidora de Aves 22 DR**.

## Archivos incluidos
- `index.html`: Estructura principal del sitio (encabezado con logo minimalista SVG, sección de reservas, catálogo de menú, carrito lateral y modal de administración).
- `styles.css`: Hoja de estilos responsiva con la paleta corporativa en rojo carmesí, dorado y tonos oscuros.
- `app.js`: Lógica completa de reserva de mesas con control booleano (`15` cupos entre semana / `20` en fin de semana, máximo `4` personas), carrito de pedidos por WhatsApp, persistencia en `localStorage` y panel de administración protegido (`mayerjavi1984`).

## Cómo ejecutar
Abre `index.html` directamente en cualquier navegador web o despliégalo en un servidor estático (GitHub Pages, Netlify, Vercel o Apache/Nginx).
